# ngvu-engineering

General ngvu engineering skills, written by Vu Nguyen.
They are the skills `slots.yaml` and the factory rely on (`pr-review`, `daily-router`,
`ticket-workflow`, the `ngvu-flow-logs`, `ngvu-pod-health` and `playwright-checking` skills used by `/ngvu-factory:ngvu-factory verify`) plus the backend,
database, cloud, observability and architecture packs.

Not included, because they come from third parties whose origin and license are not recorded:
`pr`, `tdd`, `grilling`, `grill-me`,
`grill-with-docs`, `codebase-design`, `improve-codebase-architecture`, `domain-modeling`,
`prototype`, `research`, `setup-pre-commit`, `setup-ts-deep-modules`, `migrate-to-shoehorn`,
`graphify` and the planning-workflow set. Install those from their upstream on each machine.

Skills link to `~/.claude/rules/*.md`; `deploy/bootstrap` installs those files from `core-governance`.

Plugin skills are invoked as `/ngvu-engineering:<skill>`.
