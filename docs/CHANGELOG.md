# Changelog

## 0.1.0 - 2026-11-06

First public release of ngvu-factory: the plugin marketplace (`core-governance`, `ngvu-factory`,
`ngvu-engineering`), the deploy kit, the guard hooks, the dashboard and the tests.

It is a personal project and ships no organisation-specific material: ticket prefix, hosts and projects are
placeholders (`VUNG`, `example.atlassian.net`,
`github.com/nguyengiavu`, `com.ngvu`). Replace them in `config/` and `deploy/kit.json` for your own setup.
